flagforge://novelties

C++17 backend + React/TypeScript frontend. A CTF platform with 13 features that a plain scoreboard does not have.

13 novelties built into the project

1Real challenges, real files

27 challenges; pcap, ELF/PE binaries, memory dump, WAV, PNG. Each file shows its SHA-256 and some are unique per team.

Challenge page → Files
2In-browser terminal

Play the whole CTF from a shell: ls, cat, get, submit, hint, score, nc. Uses the real API.

Top nav → Terminal
3Simulated nc services

Overflow, format-string and ret2win pwn challenges over real TCP. Models the C program; never runs player input.

nc localhost 9101 / 9102 / 9103
4Event replay

Scrub or play back the whole competition at 1x to 8x, with live standings and score moves.

Scoreboard → replay
5Mission-control mode

Full-screen projector view: big top-10, live feed, countdown, first-blood banner. Press F for fullscreen.

/projector
6Skill-tree graph

Challenges drawn as a prerequisite graph; solved paths glow, locked nodes are dimmed.

Challenges → tree
7Smarter anti-cheat

Per-team files catch flag sharing. Fast-solve and correlated-solve rules, tunable by admins (0 = off).

Admin → Alerts → Rules
8Writeups after solving

Official writeup stays locked until your team solves the challenge (or the event ends).

Challenge page → writeup
9Challenge pack format

One folder per challenge: challenge.json, description.md, writeup.md, files/. Import with one script.

challenges/ , docs/challenge-packs.md
10Skill radar and badges

Per-category radar and derived badges: first blood, master of a category, all-rounder, hard hitter, veteran.

Player and team profiles
11Team war-room chat

Private chat per team. Only members can read or post; history survives a restart.

Team → war-room
12Persistent alerts and feed

Anti-cheat alerts and the activity feed are saved, so a server restart loses nothing.

Admin → Alerts
13Metrics endpoint

Prometheus text metrics: request timings, solves, alerts, live streams. Ready for Grafana.

GET /metrics
Also in the box

7 colour themes with a neumorphic terminal look; admin console (challenges, attachments, writeups, teams, event control); first blood and dynamic decay scoring; costed hints; scoreboard freeze; per-team dynamic flags; 30 demo teams.

Backend: C++17, CMake, Ninja. Frontend: React 18, Vite, Tailwind, TanStack Query, recharts, framer-motion
